# Contributing

- Bugs and questions: open an issue, or email hello@useoutlet.dev.
- Security issues: see [SECURITY.md](SECURITY.md). Never open a public issue for one.
- Changes: open a pull request against main. Keep it small. Add a test. Run `npm test` in sdk/ and `pytest` in sdk-python/.
- Licenses: the SDK and examples are MIT, the spec is CC-BY-4.0.
